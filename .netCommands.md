#### .net version.

    - dotnet --version

#### .net version info

    - dotnet --info

#### .net create new project list

    - dotnet new list

#### clean project
    - dotnet clean

#### .net build project

    - command + shift + B + (select dotnet: build)
    - dotnet build

#### list all packages installed
    - dotnet list package
    
#### install package 
    - dotnet add package [packageName]
    
#### after installing package (important check)
    - dotnet restore

#### run project

    - F5
    - dotnet run
    - dotnet watch run (first time running project)
