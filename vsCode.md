# VScode

#### Open vscode setting

    - Win: Ctrl + ,

#### Select all occurances in file

    - Win: Ctrl + Shift + L

#### Select specific occurances in file

    - Win: Ctrl + D

#### Multiple cursor

    - Win: Alt + Click

#### Select all content and move to next line

    - Win: Ctrl + L

#### Open Preview on split screen

    - Win: Ctrl + K, V

#### Open Preview as single file

    - Win: Ctrl + Shift + V

#### Close Opened file

    - Win: Ctrl + F4

#### New terminal

    - Win: Ctrl + Shift + `

#### Navigate to terminal

    - Win: Ctrl + `

#### Hide terminal

    - Win: Ctrl + J
           Ctrl + `

#### Jump to opened pages

    - Win: Alt + [fileTabNumber]
           Ctrl + Tab
           Alt + [left/right Arrow]

#### Search and Open File

    - Win: Ctrl + P

#### Close file

    - Mac: Cmd + W

    - Win: Ctrl + W
           Ctrl + F4

#### Close all files

    - Win: Ctrl + shift + W

#### Zoom in

    - Win: Ctrl + =

#### Zoom out

    - Win: Ctrl + -

#### Empty split screen

    - Win: Ctrl + number(starting 2)

#### Split screen with current page

    - Win: Ctrl + \

#### Move cursor word by word

    - Win: Ctrl + sideArrow

#### Find

    - Win: Ctrl + F

#### Find and replace

    - Win: Ctrl + H

           1. To replace one by one occurance

              Ctrl + Enter

           2. To replace all occurances

              Ctrl + Alt + Enter

#### Duplicate contents

    - Win: Alt + Shift + Up/DownArrow

#### Move contents

    - Win: Alt + Up/DownArrow

#### Go to specific code block

    - Win: Ctrl + Shift + O

#### Go to line number

    - Win: Ctrl + G

#### Delete whole word from left side of the cursor

    - Win: Ctrl + Backspace

#### Delete whole word from right side of the cursor

    - Win: Ctrl + Backspace
