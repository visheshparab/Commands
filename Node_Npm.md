# Node

1. Node version.

   - node --version
   - node -v

2. JavaScript code editor

   - node

3. Run JavaScript file

   - node fileName

## Npm

1. All version.

   - npm version

2. npm version.

   - npm --version
   - npm -version
   - npm -v

3. initializing new project -> package.json file

   - npm init

4. Run file which is added in package.json under script.

   - npm run start

5. Install express

   - npm install express --save
   - npm i express

6. Install express specific version(Here version eg. 4.18.2)
   - npm install express@4.18.2
   - npm i express@4.18.2

7. Install all packages which are available in dependencies under package.json file
   - npm install
   - npm i
